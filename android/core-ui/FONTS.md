# SUIT

앱의 한글·영문 UI는 SUIT Regular(400), SemiBold(600), Bold(700)를 사용한다. 네트워크 다운로드 없이 APK에 포함된 원본 TTF를 읽는다.

- 원본: [sun-typeface/SUIT](https://github.com/sun-typeface/SUIT/tree/55118d981336d8fce005eb62888c12c0568ef7b0)
- 리비전: `55118d981336d8fce005eb62888c12c0568ef7b0`
- 원본 경로: `fonts/static/ttf/SUIT-{Regular,SemiBold,Bold}.ttf`
- 라이선스: SIL Open Font License 1.1. 원본의 전체 저작권·라이선스는 [`SUIT-OFL.txt`](../app/src/main/assets/SUIT-OFL.txt)에 보존하고 APK에 포함한다.
