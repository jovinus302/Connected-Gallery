# 사진 연결 실기기 검증 및 수정

## 환경과 재현
- Galaxy S23 Ultra (SM-S918N), Android 16, 기존 앱 데이터 유지 설치.
- 사진 연결 버튼 실행 후 1,000장 표시 유지. 서버 동기화는 실패.
- 사진 상세 진입 시 기존 `PC 연결을 확인하면 주변 사진을 볼 수 있어요` 문구 재현.
- 기기의 서버 주소는 localhost 8767 포트. ADB 역방향 전달은 8000 포트만 존재하며 PC의 8767 접속은 연결 거부. 별도 저장된 런타임 서버 설정도 접근 불가.

## 문제 목록과 수정 계획
1. 상세 화면의 PC 연결 안내: 분석 서버 연결 안내로 교체하고 재시도 동작 검증.
2. HTTP 인증 오류가 일반 동기화 실패로 표시됨: 401/403은 접속 키 안내, 다른 HTTP 오류는 상태 코드 안내를 추가. 응답 본문과 접속 키는 노출하지 않음.
3. 단계별 오류 처리 회귀 방지: 로딩 실패 후 사진 유지·재시도와 오프라인 상세 화면 복구를 실기기 테스트에 추가.
4. 실제 분석 연결 불가: 유효한 서버 주소와 실행 중인 서버 필요. 현재 설정을 임의의 서버로 바꾸지 않았으며 분석 성공 검증은 남아 있음.

## 완료 및 검증
- 1~3 구현 완료.
- `:data:testDebugUnitTest`, `:app:assembleDebug` 통과.
- `:feature-explore:connectedDebugAndroidTest`: 실기기 7개 테스트 모두 통과. 결정적 저장소 fixture를 사용한 UI 테스트이며 실제 모델 분석 정확도 검증은 아님.
- 최종 APK 재설치 성공. 실제 앱에서 사진 상세의 변경된 안내, 목록 복귀, 사진 연결 버튼 이후 사진 1,000장 유지 확인.
- 권한 최초 요청/거부 및 선택 사진 권한 전환은 이번 기기 상태에서 수동 검증하지 않음.
- 실제 서버 연결 및 분석 성공은 위 환경 문제로 미검증.

## 연결 복구 후 재검증
- 분석 서버를 localhost 8765에서 실행하고 인증된 `/manifest` 응답을 확인.
- `scripts/configure-device.py --usb`로 USB 역방향 포트 전달과 기기 설정을 함께 복구.
- 실기기에서 **1000장의 사진 동기화 완료** 문구 확인. 상세 화면에서 서버가 반환한 촬영일과 분석 진행 상태 확인. 모델 분석 전체 완료와 결과 정확도는 별도 검증 대상.
- 구성 스크립트는 저장 전에 인증 및 API 버전을 확인하므로 접근되지 않는 설정으로 기기를 덮어쓰지 않음. USB 주소는 해당 포트를 자동 전달. `scripts/connect-device.ps1 -Usb`도 지원.
- `tests/test_device_configuration.py`: 인증 성공, 인증 실패, API 비호환, 서버 오류, 원격 HTTP 거부 5개 통과.
- 현재 복구 경로는 USB이며 케이블과 PC 서버가 필요함. HTTPS 터널은 DNS 실패로 사용하지 않음.

## HTTPS 추가 복구
- Cloudflare 임시 호스트의 DNS 전파 후 인증된 HTTPS `/manifest` 200 및 미인증 요청 401 확인.
- 기기 설정을 검증된 HTTPS 주소로 다시 갱신하고 서버의 USB 8765 전달 제거.
- 최초 터널에서는 origin 연결 reset 및 502 발생. 터널 유휴 연결 시간을 2초로 줄여 Uvicorn 기본 유휴 시간보다 먼저 닫도록 변경한 뒤, 실기기에서 HTTPS 사진 1,000장 동기화 완료 확인. 이 변경이 모든 연결 reset 원인을 제거한다는 의미는 아님.
- 서버가 분석으로 바쁠 때 health 시간 초과를 서버 종료로 오인해 중복 기동하던 문제를 방지: 검증 시간을 늘리고 포트가 열려 있으면 재기동하지 않음.
- 연결 및 HTTPS 진단 테스트 8개 통과. HTTPS 상태에서는 USB가 필요 없지만 PC 서버와 터널은 실행 중이어야 함. 임시 터널 재생성 시 주소를 다시 설정해야 함.
