# Connect 결과의 최종 근거 수정

2026-09-07 · agent spec 18 · `v13-reviewed-result-revision`

후보 검토를 통과한 사진도 이후의 독립 검토에서 특정 관계나 설명을 입증하지 못할 수 있다. 한 후보의 불확실성 때문에 근거 있는 다른 연결까지 모두 사라지는 문제를 줄이되, 검토 기준을 낮추지 않는다.

- 첫 그룹 제안은 기존 후보 전부를 정확히 한 번씩 포함한다. 원본 crop과 후보 한 장을 별도로 보여주는 독립 검토가 그룹 제목·그룹 이유·해당 카드 이유를 확인한다. 앞선 후보 이유도 검토할 주장이지 확정된 사실이 아니다.
- 실패 피드백을 받은 경우에만 모델이 두 번째이자 마지막 `items + groups + omitted` 수정안을 제출한다. 남긴 사진의 이유를 다시 쓰고, 제외한 사진마다 근거와 `rejected` 또는 `uncertain` 판단을 명시한다. 코드가 불확실한 사진을 자동 삭제하지 않는다.
- 남긴 ID와 명시적으로 제외한 ID는 원래 후보 전체를 중복 없이 정확히 처리해야 한다. 새 ID·원본 사진 추가·무단 누락은 거부한다. 최종 그룹은 남긴 사진만 정확히 한 번씩 포함한다.
- 남긴 사진의 카드 이유와 그룹 제목·이유는 새로운 독립 검토를 모두 통과해야 한다. 검토자는 이전 피드백을 받지 않고 원본과 해당 후보의 실제 이미지, 현재 검토할 설명만 받는다. 모든 사진 제외는 확인된 연결 없음의 증거가 아니므로 실패/불완전으로 남긴다. 기존 검색의 불완전 상태도 성공으로 올리지 않는다.
- 최초 제안과 수정안은 기존 두 라운드·한 deadline·제한된 검토 동시성을 공유한다. 실패·시간 초과·취소·사진/갤러리 변경 결과는 준비 완료 캐시로 쓰지 않는다. 추가 추측 반복은 없다.

외부 결과 스키마는 `items + groups + complete + grouping_status`를 유지한다. 원래 후보, 수정된 이유와 명시적 제외 사유, 검토 결과는 내부 실행 이벤트에 기록한다. 제외는 관련 사진이 절대로 없다는 주장이나 전체 회수율 보증이 아니다. 배포 데이터는 기존대로 실행 이력을 제거하며, 사진 상세 맥락의 별도 캐시 계약에는 이 변경을 적용하지 않는다. 이전 Connect 캐시는 새 버전에서 재사용하지 않는다.
