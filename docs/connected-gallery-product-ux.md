# Connected Gallery 제품과 사용자 흐름

사진 속 대상을 따라가며, 도착한 사진의 맥락을 이해하고 다시 탐색하는 갤러리다. MVP는 선택 대상의 관련 사진을 찾는 **Connect**와 열린 사진의 주변 관계를 보여주는 **자동 맥락(Organize)**으로 구성한다.

## 사용자 흐름

**사진 열기 → 대상 선택 → 이 대상으로 사진 찾기 → 관련 사진 → 사진 열기와 자동 맥락 → 다음 탐색**

1. 사진 속 사람·사물·텍스트·장소를 선택한다. 필요한 경우 길게 눌러 수동 영역을 선택한다. 선택 영역과 대상 이름이 표시되며, 검색 전 선택을 해제하거나 뒤로 돌아갈 수 있다.
2. **이 대상으로 사진 찾기**를 누르면 Connect가 선택 대상과 관련된 사진을 보여준다. 결과는 두 열의 사진과 근거 설명으로 표시한다.
3. 결과 사진을 열면 큰 사진 아래에 함께 볼 사진과 이유가 나타난다. 맥락 표시를 위해 별도 버튼을 누를 필요는 없다.
4. 맥락 그룹 제목을 누르면 확보된 전체 목록을 펼친다. 맥락 속 사진을 열거나 현재 사진의 새로운 대상을 선택해 탐색을 이어간다.
5. 돌아가기는 이전 사진·선택·결과·맥락·스크롤을 복원한다.

사진이 상세 화면의 중심이며 맥락은 다음 탐색을 선택하는 단서다. 화면 문구는 기능명보다 ‘이날 함께 찍은 사진’처럼 실제 내용을 드러낸다.

## Connect와 자동 맥락

Connect는 선택 영역을 기준으로 관련 사진을 찾는다. 자동 맥락은 열린 사진 전체를 기준으로 관계를 구성한다. 같은 사진의 맥락은 그 사진을 어떤 탐색 경로로 열었는지에 따라 달라지지 않는다.

| 맥락의 예 | 함께 볼 이유 |
|---|---|
| 시간·사건 | 사진이 속한 날이나 장면의 흐름을 이해한다. |
| 사람 | 함께 등장한 사람들의 다른 순간을 본다. |
| 장소 | 같은 장소의 다른 장면을 본다. |
| 대상 | 대상이 등장한 다른 상황을 본다. |
| 변화·차이 | 반복된 장면이나 대상에서 달라진 것을 이해한다. |

이는 가능한 관계의 예시다. 고정 분류나 필수 섹션으로 사용하지 않는다. 에이전트가 사진과 확보한 후보를 관찰해 관계·제목·설명·구성 사진을 결정한다. 근거가 없으면 맥락을 억지로 만들지 않는다. Connect 후보 밖의 사진도 별도로 확보하고 관찰한 뒤 맥락에 포함할 수 있다.

## 표시와 상태

준비된 맥락은 사진과 함께 표시하고, 미준비 상태에서는 자동으로 준비를 요청한다. 준비 중·준비 실패·확인된 맥락 없음을 구분하며 실패에는 재시도를 제공한다. 새 사진을 열면 그 사진의 맥락으로 전환하고 이전 응답이 현재 화면을 덮지 못하게 한다.

맥락 그룹을 펼치는 동작은 확보된 목록을 보여준다. 추가 검색을 자동으로 시작하지 않는다. 내부 캐시는 사진·모델·정책·갤러리 버전에 맞는 결과를 재사용한다.

## 근거와 데이터 원칙

- 촬영일은 메타데이터와 출처를 확인한다. 같은 날이라는 사실만으로 같은 사건을 확정하지 않는다.
- 함께 등장한 인물의 가족·친구 관계나 사진만으로 알 수 없는 소유·구매 사실을 단정하지 않는다.
- 같은 제품 표기, 시각적 유사성, 동일한 물리적 개체를 구분한다.
- 실제 관찰한 후보와 접근 가능한 사진만 결과에 포함한다. 생성 프롬프트나 평가 정답을 판단 입력에 넣지 않는다.
- 코드는 접근 권한·삭제·버전·스키마·실행 예산을 검증하고, 의미 판단은 에이전트가 수행한다. 모델 검토와 별도로 실제 사진의 정확도를 검수한다.
- Android 원본 사진은 유지하고 모델 접속 키는 PC에서 관리한다.

## MVP 범위

개인 Android 갤러리와 PC 서버를 사용하며 접근을 허용한 사진 최대 1,000장을 연결한다. 사진 연결·분석, 대상 선택, Connect, 자동 맥락, 연속 탐색, 복원과 재시도를 제공한다.

사용자가 관리하는 영구 사진 묶음, Time/Timeline, 공유, 영상, 구매 추천, 완벽한 인물 식별은 MVP에 포함하지 않는다.

## 수용 기준

- 대상 선택으로 관련 사진을 찾고, 도착한 사진의 근거 있는 맥락을 별도 요청 없이 볼 수 있다.
- 선택 대상이나 열린 사진이 바뀌면 결과와 맥락도 해당 기준에 맞게 달라진다.
- 사진·메타데이터를 직접 확인해 관련 사진 회수와 설명 정확도를 각각 검수한다.
- 연속 3회 탐색에서 도착 여부뿐 아니라 각 맥락이 다음 선택에 어떤 단서를 제공했는지 확인한다.
- 준비됨·미준비·실패·맥락 없음, 실제 화면 대기 시간, 뒤로 가기 복원을 확인한다.
