# 자동 맥락·Connect 통합 검증

2026-09-08. Space를 제외한 현재 제품 계약의 구현과 검증을 기록한다. 과거 Spaces 완료 기록을 현재 MVP 완료로 해석하지 않는다. 수치는 [기계 판독 기록](context-ux-validation.json)과 구분해 읽는다.

## 구현

- 기존 Connect 결과 그룹과 준비 결과 조회, 후보·최종 설명의 독립 검토를 통합했다. 그룹 생성은 확보한 후보 위에서만 진행한다.
- 사진 전체의 맥락 GET/prepare API, 스냅숏 캐시·작업 중복 방지·복구·실패 구분을 추가했다. 사진·계획·각 멤버·최종 문구의 근거 검토를 유지한다.
- Android는 사진을 열면 맥락을 자동 조회하고 미준비면 생성한다. 같은 날을 명시적으로 누를 필요가 없다. 그룹 전체 보기, 다음 사진 열기, 새 대상 선택, 뒤로 복원과 순서 있는 저장을 구현했다.
- PC 합성 갤러리 화면·준비/평가/패키지 도구도 소스에 포함한다. 이전 데모의 캐시나 측정값을 새 정책의 완료 결과로 승격하지 않는다.
- 원본 main의 Space 제거를 유지했다. 기존 저장 데이터는 삭제하지 않았다.

## 코드와 기기

서버 회귀 테스트 336개 통과.

Android `assembleDebug testDebugUnitTest lintDebug` 통과. 단위 테스트 29개, lint 오류 0개·기존 경고 6개. 브라우저 상태·레이아웃 테스트 22개 통과.

Galaxy S23 Ultra SM-S918N / Android 16에서 총 5개 테스트가 통과했다. 좌표·지연 로딩된 영역 탭·확대 후 길게 누르기 3개와 새 맥락 UI 2개다. 새 UI 테스트는 테스트 저장소의 고정 응답으로 와인→식사→디저트→풍경을 세 번 이동하고, 자동 맥락·그룹 전체 보기·뒤로 복원·실패 후 재시도를 확인한다. 이는 실제 모델의 의미 정확도 시험이 아니다. 연결된 기존 앱에 APK를 `install -r`로 설치했다.

앱 시작 시 저장된 화면 복원이 사용자의 새 열기를 덮어쓰는 경합과, 맥락 재확인 중 임시 목록이 저장된 스크롤을 초기화하는 문제를 수정했다. 이전 사진의 query를 새 사진에 상속한 과거 기록도 이관한다. 앱 프로세스를 강제 종료한 뒤 실제 개인 사진 화면을 복원하는 전체 시나리오는 아직 별도 검증 대상이다.

## 실제 사진

원본 DB를 읽기 전용으로 복제했다. 복사 당시 사진·분석 레코드는 각각 1,000개였다. 이 수치는 과거 386장 중단 기록보다 뒤의 저장 상태이며 분석 품질이나 인덱스 완전성을 새로 보증하지 않는다.

사용자가 승인한 원본 와인 사진 1장과 주변 최대 24장 범위에서 기존 Proxy를 사용했다. 재시도 전체의 서로 다른 관찰 사진 수를 별도로 제한했다. 원본 갤러리 파일·기존 서버는 변경하지 않았으며 개인 사진·전체 모델 응답·접속 정보는 Git에 포함하지 않는다.

첫 두 실행은 제출 예산 안에 검증된 결과를 내지 못했다. 잘못된 멤버에 대한 구체적인 복구 정보와 모델 경계의 짧은 사진 ID 처리를 추가한 v4 실행은 42.27초에 준비 완료가 됐다. 준비 조회 5회는 PC loopback에서 1.61~8.55ms였다. 이 수치를 사진 렌더링을 포함한 휴대폰 체감 지연으로 해석하지 않는다.

**v4 결과는 수동 품질 검수에서 미달했다.** 포스터 1장과 매장 진열 사진 4장을 한 그룹에 넣고 포스터로 설명했다. 독립 모델 검토가 이런 과도한 일반화를 놓칠 수 있음을 확인했다. 같은 날 주변 장면의 효용도 입증하지 못했다. 이 결과를 정답 캐시나 준비율의 성공 근거로 배포하지 않는다.

그 뒤 v5에서 초기 후보 공급을 보완했다. 알려진 촬영 시각이 있으면 원본과 시각이 가까운 메타데이터 최대 40장을 첫 관찰 후보로 제공하고 나머지 목록 예산을 남긴다. 날짜가 없는 사진은 기본 목록 순서를 사용한다. 이는 후보 공급 prior이며 같은 날·사건 그룹을 생성하는 규칙이 아니다. 에이전트는 이 후보를 버리거나 다른 도구로 확장할 수 있고 모든 결과는 실제 이미지 검토를 거쳐야 한다.

v5 실제 실행은 **32.22초**, 그룹 3개·사진 13장으로 완료됐다. 원본과 멤버 전체 이미지를 직접 검수해 식사 테이블의 여러 장면·와인을 따르는 장면·음식 사진과 그룹 설명의 대응을 확인했다. 이 중 음식 중심 사진처럼 선택한 와인이 주제가 아닌 주변 장면도 포함됐다. 해당 표본의 제한된 검수 통과이며 일반 정확도나 사용자 효용 전체의 증거는 아니다. 처음 v4의 과도한 일반화가 있었던 사실을 유지한다.

v5 준비 결과 GET 5회는 PC loopback에서 1.85~8.95ms였다. 전체 재시도에서 실제 모델에 관찰시킨 서로 다른 사진은 원본 포함 19장으로 승인한 최대 25장 안에 머물렀다. 개인 사진을 새로 보내는 검증은 여기서 마쳤다.

## 남은 완료 조건

실제 사진의 다양한 장면에서 문구·멤버·날짜 근거와 ‘다음에 무엇을 보고 싶어지는가’를 반복 확인해야 한다. 실기기 3hop UI 통과와 실제 개인 사진의 end-to-end 성공을 구분한다. 준비가 없는 첫 실행 지연, 선행 준비 우선순위·비용·준비율, 재시작 복원, 최종 제품 지표는 아직 완료 판정의 근거가 충분하지 않다.
