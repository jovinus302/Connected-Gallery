## 이번에 구현·보완한 것

1. 에이전트가 제출한 분석 근거와 필수 임베딩을 한 트랜잭션으로 저장한다. 임베딩 실패 시 새 분석을 완료로 저장하지 않는다. 기존 근거만 재인덱싱하는 복구 도구와 진행 조회 API를 추가했다.
2. 모델을 처음 동시에 불러올 때 발생한 Transformers/Paddle import 충돌을 방지했다. GPU 추론은 1개로 유지하고 CPU OCR·얼굴 작업은 별도 잠금을 사용한다.
3. Same moment에서 에이전트가 시간 범위를 정해 후보를 찾는 도구를 추가했다. 사건의 의미 판단과 최종 선정은 시각적 근거를 확인한 에이전트가 수행한다.
4. 현재 기준 사진을 Follow 검색 후보와 최종 결과에서 제외한다. 계약 테스트는 통과했지만 이 마지막 변경은 실제 기기에서 검증하지 않았다.
5. 분석 동시 실행 수를 설정으로 분리했다. 현재 로컬 설정은 5개이며, 기본값은 3개다. 속도 개선 효과를 입증한 비교 측정은 아직 없다.

고정 카테고리·키워드 매핑·검색 가중치 기반 의미 판단 fallback은 추가하지 않았다. 앞선 커밋의 제한된 제출 수정, 중복 분석 방지, GPU 실행 환경도 유지한다.

## 다음에 해결할 것

1. 결과 저장 후 발생한 OperationalError 1건의 정확한 SQLite 오류를 확인한다. 동시 체크포인트 쓰기 충돌 가능성은 가설이다. DB는 이미 WAL이며, 단순 WAL 설정으로 해결됐다고 판단하지 않는다. 분석 저장 성공과 실행 실패 상태의 정합성을 보완해야 한다.
2. 남은 분석을 재개하고 사진별 준비 상태·활성 작업 중복·누락을 재확인한다. 과거 실패 실행 21건을 현재 실패 사진 21장으로 해석하지 않는다.
3. 최신 기준 사진 제외 정책으로 API 탐색을 재검증하고, 이전 버전 결과 캐시가 새 정책을 우회하지 않도록 버전 또는 무효화 범위를 확인한다.
4. 휴대폰 잠금 해제 후 실제 사진에서 3회 이상 연속 hop, Time의 anchor 유지, 빠른 연도 변경, 뒤로 가기 복원을 검증한다. 현재 기기는 잠겨 있었으며 이를 우회하지 않았다.
5. 전체 분석 완료 후 최종 Spaces를 만들고 실제 500~1,000장 품질·성능·사용자 평가를 수행한다.

```powershell
.\scripts\connect-device.ps1
```
