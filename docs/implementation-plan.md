# Connected Gallery 구현 기준

## 구현 목표

[제품과 사용자 흐름](connected-gallery-product-ux.md)에 따라 **사진 연결 → 대상 선택 → 관련 사진 → 자동 맥락 → 다음 탐색**을 제공한다. Connect는 선택 영역, 자동 맥락은 열린 사진 전체를 기준으로 동작한다.

## 구성

| 영역 | 책임 |
|---|---|
| Android `app` | 앱 조립과 서버 설정 |
| Android `domain` / `data` | 도메인 계약, 사진 접근·동기화·서버 통신·저장 |
| Android `core-ui` | 사진 뷰어와 좌표 변환 |
| Android `feature-library` / `feature-explore` | 사진 목록, 대상 선택, 결과·맥락 표시와 탐색 복원 |
| 서버 `domain` / `application` | 데이터 계약과 유스케이스 |
| 서버 `agent_specs` / `agent_runtime` | 모델 지시, 도구 실행, 예산과 작업 상태 |
| 서버 `gallery_tools` / `adapters` / `bootstrap` | 사진 관찰·검색, 저장소·모델 연결과 실행 구성 |
| `web/demo` | 준비된 사진·Connect·맥락을 탐색하는 브라우저 데모 |

Android는 Kotlin/Compose를 사용하고 PC 서버는 Python/FastAPI, SQLite와 벡터 검색을 사용한다. API의 세부 필드는 서버 OpenAPI와 도메인 모델을 따른다.

## 기능별 구현 조건

### 사진 연결과 분석

접근을 허용한 사진 최대 1,000장의 메타데이터와 분석용 이미지를 연결한다. 실제 이미지를 관찰해 설명·텍스트·영역과 검색 인덱스를 준비한다. 사진 버전 변경·권한 철회·삭제 시 파생 데이터가 유효하지 않게 처리한다. 전송과 분석은 실패 후 재개할 수 있어야 한다.

### Connect

선택한 대상의 근거를 바탕으로 후보를 검색하고 실제 사진을 확인한 뒤 결과를 제출한다. 대상 선택과 수동 영역 선택을 지원하며 결과 사진에서 새 대상을 선택해 탐색을 계속한다. 취소되거나 오래된 요청이 최신 선택의 결과를 덮지 못하게 한다.

### 자동 맥락

사진 전체를 기준으로 후보를 확보하고 함께 볼 이유를 구성한다. 이전 Connect 결과나 탐색 경로를 맥락 판단 입력으로 사용하지 않는다. 준비 결과를 재사용하고 미준비 맥락은 화면에서 자동 요청한다. 조회·준비 API, 검토와 계산 예산은 [사진 맥락 계약](photo-context-contract.md)을 따른다.

### 탐색 상태와 복구

사진·선택 대상·결과·맥락·펼침·스크롤을 복원한다. 준비 중·실패·확인된 빈 결과를 구분한다. 작업 취소·시간 초과·서버 재시작과 갤러리 변경에서도 유효한 결과만 표시한다. 캐시는 사진·모델·정책·갤러리 버전으로 유효성을 확인한다.

### 서버 연결과 데이터 보호

PC 서버에 HTTPS와 접속 키로 연결한다. 앱에서 연결·인증·API 호환성을 확인한 뒤 설정을 저장한다. 모델 Proxy 키는 PC에만 두고 앱 접속 키는 Android Keystore로 암호화한다. 운영 절차는 [PC 서버 안내](pc-server.md)를 따른다.

## 검증 계획

| 주장 | 필요한 증거 |
|---|---|
| 연결·분석이 동작함 | 허용 사진의 전송·분석·인덱스 준비와 중단 후 재개 확인 |
| 대상에 맞는 사진을 찾음 | 실제 사진에서 대상별 관련성·무정답 검수 |
| 맥락이 사진 이해를 도움 | 원본과 후보·날짜 출처를 대조한 관계·문구 검수, 다음 선택의 이유 기록 |
| 탐색 상태가 유지됨 | Android 연속 3hop, 선택 변경, 뒤로 가기·펼침·스크롤 복원 |
| 실패와 변경을 처리함 | 취소 직후 응답, 서버 재시작, 연결 중단, 권한 철회·삭제·버전 변경 검사 |
| 대기 시간이 적절함 | 캐시 조회, 새 모델 준비, 실제 사진·맥락 표시 시간을 각각 측정 |
| 기존 동작을 보존함 | Python 테스트와 Android 단위 테스트·lint·빌드 |

합성 데모와 실제 사진, PC API 측정과 Android 화면 측정은 구분한다. 테스트 통과만으로 사진의 의미 품질이나 사용자 경험을 입증하지 않는다. 결과에는 사용 버전·사진 수·조건·실패·미검증 범위를 기록한다.

## 확인이 필요한 항목

실제 갤러리의 관계 정확도와 후보 누락, 규모별 준비 시간과 비용, 휴대폰에서의 대기 시간은 해당 환경에서 측정한다. 탐색할 가능성이 높은 사진의 선행 준비 우선순위는 별도 설계 항목이다. 측정되지 않은 품질·성능을 완료로 간주하지 않는다.
