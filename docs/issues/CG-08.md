# CG-08: Explorer와 후보의 시각 확인

## 구현 범위
선택 영역 → 후보 확보·시각 확인 → 독립 검토 → 근거 있는 결과 그룹. `/explorations/ready`는 모델 호출 없이 현재 버전의 준비 결과를 조회한다.

## 선행 작업
CG-07

## 완료 기준
실제 ID·확인한 이미지·명시적 요청 범위만 제출한다. 그룹 생성은 독립 검토를 통과한 후보 위에서만 진행하며 그룹을 위한 새 검색은 없다. 결과 수정의 제외·유지·설명 변경을 검토하고, 오래된 갤러리 revision은 게시하지 않는다.

## 검증 시나리오
허구 ID·미확인 후보·요청 범위 밖 결과, 그룹 멤버의 추가·누락·중복, 검토 중 삭제·변경, 실패를 완료 캐시로 올리는 동작을 거부한다. [통합 검증](../context-ux-validation.md) 참조.

See → Tap → Follow. 의미 판단은 full agentic. Time은 후속 기능(CG-15)이며 MVP 범위는 Organize + Connect. 실제 사진 검증은 소스 구현과 별도로 기록한다.
