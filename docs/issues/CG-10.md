# CG-10: Related·Same moment·기록

## 구현 범위
Related/Same moment 방향 전환과 화면 기록. 기존 저장된 연도 필터를 해제하고 Time UI를 제거한다.

## 선행 작업
CG-09

## 완료 기준
anchor 보존, Same moment는 사건 맥락, 뒤로 가기·결과·스크롤 복원. 현재 화면과 뒤로 가기 기록에 숨은 연도 필터가 남지 않는다.

## 검증 시나리오
방향 전환의 응답 경합·이전 요청 취소·scroll 복원·구버전 연도 필터 이관. Time 전용 검증은 CG-15로 이관한다.

See → Tap → Follow. 의미 판단은 full agentic. Time은 후속 기능(CG-15)이며 MVP 범위는 Organize + Connect. 실제 사진 검증은 소스 구현과 별도로 기록한다.
