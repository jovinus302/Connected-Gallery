# CG-11: 사진 상세의 Organize 맥락

2026-09-07 개정 · 제품 범위 결정이며 구현 완료 표시가 아니다. [제품·UX 기준](../connected-gallery-product-ux.md)을 따른다. Space 진입·자동 생성 제거 부분은 [코드 검증](../space-removal-validation.md)을 완료했고, 사진 상세 서버와 Android UX를 통합했으며 [검증과 남은 한계](../context-ux-validation.md)를 별도로 기록한다. 이전 제목은 ‘Organizer·Spaces·사용자 수정’이었다. 기존 Spaces 기능의 검증·완료 기록은 이 새 범위의 완료를 의미하지 않는다.

## 구현 범위

Connect 결과에서 사진 한 장을 열면, 그 사진의 근거 있는 주변 맥락과 사진 미리보기를 상세 화면에 함께 표시한다. 최초 맥락 노출에 ‘이날 사진’ 또는 ‘정리하기’ 클릭을 요구하지 않는다. 에이전트가 사진·메타데이터를 관찰해 관계·설명·구성을 결정한다. 시간·사건, 사람, 장소, 대상, 변화는 참고 어휘이며 고정 분류 규칙이 아니다.

Space 생성·자동 게시·저장·목록·편집·사용자 쓰기 권한은 제외한다. Organize는 Space 없이 동작한다. 준비된 연결·맥락 캐시와 버전·무효화·화면 복원은 유지한다. 기존 Spaces 노출·자동 생성 경로와 서버의 새 생성·편집 요청을 차단했다. 기존 저장 데이터는 삭제·마이그레이션하지 않았다.

## 선행 작업

CG-07, CG-09. 열린 사진을 기준으로 한 맥락 계약, 기존 Connect 결과 밖의 후보 확보와 근거 검토, 준비 예산·캐시 정책은 [계약 검토 결정](../context-ux-architecture.md)으로 확정했다.

## 완료 기준

- 사진을 열면 별도 맥락 요청 없이 미리보기와 관계 설명이 보인다.
- 의미 판단은 에이전트가 수행하며 유효한 사진·메타데이터 근거로 설명을 검수한다. 근거가 없으면 억지로 묶지 않는다.
- 그날의 사진이 적절한 맥락이면 와인이 없는 주변 장면도 명시적인 후보 확보·검토를 거쳐 볼 수 있다. 같은 날과 같은 사건을 동일시하지 않는다.
- 맥락 속 사진 또는 현재 사진의 새 대상을 선택해 탐색을 이어가고, 뒤로 가기로 사진·선택·맥락·스크롤을 복원한다.
- 준비된 상태·미준비·실패·맥락 없음을 구분한다. 빠른 조회와 사전 준비 비용·사진 표시 시간을 따로 측정한다.
- Space 생성·영구 저장·사용자 묶음 편집 없이 위 흐름이 성립하고 MVP의 Space 진입·자동 게시 경로를 노출하지 않는다.

## 검증 시나리오

와인 탭 → 관련 식당 사진 열기 → 그날의 주변 맥락 확인 → 다른 장면 또는 사람 선택. 각 hop에서 무엇을 알게 됐고 무엇을 더 보고 싶어졌는지 기록한다. 허구 관계, 날짜 근거 누락, 이전 사진의 맥락이 남는 오류, 삭제·버전 변경, 미준비 상태와 복원을 확인한다.

실제 사진 품질과 기기 사용성은 코드·계약 테스트와 별도로 기록한다. Time/Timeline은 후속 기능으로 유지한다. 외부 GitHub 이슈 #11의 내용·상태는 이번 문서 수정에서 변경하지 않았다.
