# CG-11: 사진 상세의 자동 맥락

## 기능

사진을 열면 사진 전체를 기준으로 함께 볼 사진·관계 설명·미리보기를 표시한다. 에이전트가 사진과 메타데이터를 관찰해 관계와 구성을 결정한다. 고정 분류나 필수 그룹을 강제하지 않는다.

## 선행 작업

CG-07, CG-09

## 완료 기준

- 별도 요청 버튼 없이 준비된 맥락을 표시하고 미준비 맥락은 자동 준비한다.
- 열린 사진 전체를 기준으로 판단하며 이전 Connect 결과나 탐색 경로를 입력으로 사용하지 않는다.
- 후보를 명시적으로 확보하고 실제 사진을 관찰한 뒤 관계·설명을 검토한다. 근거가 없으면 억지로 묶지 않는다.
- 맥락 그룹 제목은 확보된 전체 목록을 펼친다. 맥락 속 사진이나 새로운 대상을 선택해 탐색을 이어간다.
- 준비 중·실패·확인된 맥락 없음을 구분하고 실패에는 재시도를 제공한다.
- 사진·모델·정책·갤러리 버전에 맞는 캐시를 재사용하고 뒤로 가기로 이전 맥락·펼침·스크롤을 복원한다.

## 검증

대상 탭 → 관련 사진 열기 → 자동 맥락 → 다른 사진·대상 선택을 확인한다. 각 단계에서 맥락이 다음 선택에 제공한 단서를 기록한다. 관계·날짜 근거·문구 정확도, 사진 변경 시 맥락 전환, 삭제·버전 변경과 복원을 검사한다. 조회 시간·준비 비용·실제 화면 표시 시간과 사진 품질은 각각 검증한다.
