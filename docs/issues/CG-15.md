# CG-15: Time / Timeline (후속 기능)

상태: **MVP 이후로 보류 — 2026-09-07 사용자 결정**.

현재 선택한 사람·사물·텍스트·장소를 유지한 채 연도를 바꿔 탐색하는 기능이다. 재개 시 연도 스크럽, 빠른 변경 취소, 무정답, 촬영일 누락 및 실제 의미 유지 품질을 검증한다. 과거 API/기기 검증 기록은 참고 자료이며 성공 판정이 아니다.

이번 MVP의 범위와 완료 조건에는 포함하지 않는다. Android Time UI는 제거하고 구버전 저장 연도 필터를 해제한다. 촬영일 메타데이터와 기존 year API/계약 테스트는 후속 구현 기반으로 보존한다. Same moment는 Connect의 사건 탐색으로 MVP에 유지한다.
