# PC 데모 완료 기록 — 2026-09-08

이 문서는 머지 전 `3b076af` 데모 런타임(Context v3)의 수용 검증 기록이다. 검증한 소스·데이터 ZIP을 함께 사용한다. 이후 main 통합은 Context v6이며, [머지 검증·캐시 이전](demo-main-integration.md)을 별도로 따른다.

사진 한 장에서 대상을 따라가고, 도착한 사진의 자동 맥락에서 다음 관심사를 발견하는 PC 브라우저 데모다. 합성 사진 20장·주요 선택 영역 47개를 사용하며 개인 사진이나 휴대폰 연결은 필요 없다.

## 완료된 경험

1. 사진을 열면 큰 사진 아래에 함께 볼 사진과 연결 이유가 자동으로 나타난다.
2. 사진 위 표시나 대상 버튼을 선택하면 그 대상의 Connect 결과를 별도 영역에서 본다.
3. Connect 또는 자동 맥락의 사진을 열고 새 대상을 선택하며 탐색을 이어간다.
4. 뒤로 가면 사진·선택 대상·결과·맥락의 펼침 상태와 스크롤이 복원된다.

모델이 실제 사진과 확보한 후보 이미지를 보고 관계·묶음·문구·제외 여부를 결정한다. 시연 경로는 런타임 정답으로 제공하지 않는다. `prepared-only` 데모는 검토를 마친 결과를 조회하며 모델 작업을 시작하지 않는다. 별도 Organize 버튼이나 Space 생성·저장은 이 흐름에 없다.

실제 브라우저에서 확인한 경로는 다음과 같다. 정해진 순서 없이 다른 사진에서도 출발할 수 있다.

- 와인 식탁 → 병 Connect → 피크닉 → 자동 맥락 → 공원 셀피 → 사람 Connect → 기차 사진.
- 해안 아치 → 아치 Connect → 노란 셔츠 인물 → 자동 맥락 → 식당 인물 → 병 Connect → 와인 식탁.

목록에서 ‘책장’ 검색 결과 한 장, 날짜 미상 유지, 바구니·서가의 정상 빈 결과도 확인했다. 목록 검색은 저장된 설명·OCR·대상 이름·관찰 문구에서 단어를 찾는 기능이다. 새로운 자연어 검색이나 웹 검색은 포함하지 않는다.

## 실행과 데이터 전달

Python 3.12 이상에서 소스 프로젝트의 `pyproject.toml`이 있는 폴더를 사용한다. 별도 준비 데이터 ZIP을 같은 프로젝트에 풀면 `.runtime/demo/gallery.sqlite`와 이미지·프로필 파일이 생긴다.

```powershell
python -m pip install -e .
python scripts/start-demo.py --data-dir .runtime/demo --prepared-only --port 8879
```

서버가 출력한 로컬 `demo-launch.html`을 열어 일회용 시작 키로 로그인한다. 이미 사용한 키로 새 세션을 열 수 없으면 서버를 재시작해 새 키를 받는다. 전경 서버는 Ctrl+C로 종료한다. 준비 결과 조회에는 모델 API 키가 필요 없다.

사진·준비 DB·실행 이력·키는 Git에 포함하지 않는다. 소스·준비 데이터 ZIP과 SHA-256 보고서는 로컬 전달 산출물로 보존했다. 소스 ZIP과 준비 데이터 ZIP을 함께 압축 해제한 버전으로 최종 브라우저 검증을 수행했다. 이 커밋의 README와 완료 기록은 그 검증 후 추가한 전달 문서다.

새 갤러리를 준비할 때는 실제 모델 연결을 설정한 별도 준비 환경에서 `prepare-demo.py`와 `prepare-contexts.py`를 사용한다. 준비 완료 여부는 `audit-complete-demo.py`로, 실제 HTTP 조회는 `audit-demo-http.py`로 확인한다. 해당 CLI의 `--help`에 입력·보고서 옵션이 있다. 시연 데이터의 준비 결과를 새 사진의 정답으로 복사하지 않는다.

## 모델과 근거 계약

Connect primary는 `gpt-5.4`, 명시적 호환 namespace는 `claude-sonnet-5`다. 기존 모델의 key·본문·검토 증거를 보존하고 primary부터 현재 계약에 맞는 결과만 조회한다. 호환 목록은 실행 fallback이 아니다. Context 작성은 `gpt-5.4`, 독립 문구 검토는 `gpt-5.4-mini`다.

Connect spec 18 / policy `v13-reviewed-result-revision`, negative proof 1, Context spec 3 / policy `photo-context-v3-plan-and-wording-review`를 사용한다. 사진·선택 대상·버전·revision·모델·검토 증거가 맞아야 ready다. 실패나 불완전한 검토를 빈 결과로 바꾸지 않는다. Context는 Connect 밖의 후보도 명시적으로 확보하고 관찰할 수 있다.

## 속도와 비용의 범위

최종 loopback HTTP에서 47개 Connect와 20개 Context를 처음 조회한 뒤 각 항목을 5회 반복했다. 새 작업과 캐시 변경 없이 결과가 유지됐다.

| 조회 | 첫 조회 p50 / p95 | 반복 조회 p50 / p95 |
|---|---|---|
| Connect | 4.203 / 27.106ms | 1.781 / 3.006ms |
| Context | 10.346 / 24.907ms | 1.414 / 2.172ms |

HTTP 시간은 이미지 표시·모델 준비·Android 체감 시간을 포함하지 않는다. 브라우저 자동화에서는 사진 열기 284ms, Connect 선택 222ms를 각각 한 번 관찰했다. 동작과 상태 조회, 사진 열기의 스크린샷 비용을 포함한 값이며 순수 화면 렌더링 시간이나 p95가 아니다.

보존된 개발·재시도 이력의 모델 timing 787건은 누적 8,131.810초다. 병렬 실행·실패·재시도를 포함하므로 실제 경과 시간이나 갤러리 한 번의 준비 비용으로 해석하지 않는다. 원래 이미지 생성·분석의 전체 비용을 포함하지 않으며, 제공자 과금·전체 토큰 사용량은 수집하지 않아 청구 금액을 산정하지 않았다.

## 범위와 남은 제품 작업

이 기록은 해당 PC 데모의 완료 범위다. 이 데모 검증으로 Android 기기 수용 검증, 개인 갤러리 동기화·규모 확대, 운영 서버 이전까지 완료했다고 표시하지 않는다. 이후 Android·서버 개선을 합친 소스의 통합 회귀는 별도 머지 기록에 남긴다.

설정 날짜는 실제 EXIF·촬영 사실·동일 행사 근거가 아니다. 인물·장소·물리적 동일성에 대한 추정도 실제 관계를 확정하지 않는다. 일부 모델 문장의 영문 표현과 후보 누락 가능성은 남아 있다. 상품 정보 정리·웹 검색·구매 추천은 후속 범위다.
