# PC 모델 설치 후 샘플 분석 검증 — 2026-09-09

## 검증 명제

사용자가 요청한 누락 라이브러리 설치를 수행하고, 기존 샘플 24장의 실제 분석과 관련 사진 탐색을 확인한다. 기존 코드에 대한 사후 검증이며 구현 전 명제로 소급하지 않는다.

- 확정된 의도: 일상 캡처·문서·여행 사진을 실제 모델로 분석하고 앱에서 연결 결과를 볼 수 있다.
- 불변 조건: 기존 사진과 앱 데이터 보존. 모델 고정 버전 보존. 생성 프롬프트와 정답을 분석 입력에 넣지 않는다.
- 검증 계획: 의존성 검사 → 여섯 모델의 실제 추론 → 24장 분석 및 인덱스 → 관련 사진 탐색과 에뮬레이터 화면 확인.
- 판단 범위: 샘플의 기능 검증이며 일반 사진 전체의 검색 품질을 보장하지 않는다.

## 환경 준비 증거

기존 PC 서버 가상환경에 `.[vision,test]`를 `requirements.lock` 제약으로 설치했다. `pip check` 통과. PyTorch 2.9.1+cpu, Transformers 4.57.6, PaddleOCR 3.7.0, PaddlePaddle 3.3.1. GPU 드라이버는 변경하지 않았다.

고정된 Hugging Face revision을 사용하고 얼굴 모델 2개의 SHA-256을 기존 lock과 대조했다. 여섯 실제 추론 검사(이미지 벡터, 시각 텍스트 벡터, 한국어 벡터, 객체 탐지, 얼굴 탐지, OCR)가 모두 통과했다. 모델 최초 다운로드가 포함된 시간은 성능 벤치마크로 해석하지 않는다.

## 실제 샘플 실행 증거

- `/progress`: 사진 24, 분석 24, 검색 준비 24, 전체 텍스트 인덱스 24, 선택 영역 인덱스 68/68, 누락 0.
- 제품 캡처 ORBIT M2 → 설명서 1장. 실물 사진은 최종 결과에서 빠졌으므로 관련 후보를 충분히 회수했다고 판단하지 않는다.
- 항공 예약 BA217 → 여행 일정·탑승권 2장.
- 에뮬레이터에서 영수증의 ‘소라식탁’을 길게 누르고 의미 선택 → 메뉴판·식당 캡처 3장과 이유 표시. 다른 지점도 같은 상호라는 제한된 관계로 포함됐으며 동일 지점 확인의 증거가 아니다.
- 탐색 3건의 실제 최종 결과는 `pc-sample-analysis-result.json`에 기록했다. 앱 화면 증거는 로컬 `.runtime/validation/model-ready-connect.png`에 있다.
- 초기 작업 복구에서 종료된 작업 제출 오류 2건을 관찰했다. 최종 24장 분석은 모두 완료됐다. 분석 도중 시작한 첫 제품 탐색은 corpus 갱신으로 무효화됐으며, 전체 완료 후 재실행은 성공했다.

## 검증 결론과 남은 결함

환경 설치와 24장 실제 분석, 직접 선택 Connect 탐색은 PASS. 앱 전체의 자동 맥락은 PASS가 아니다. 영수증 자동 맥락 2회가 `Context wording review lacked complete exact-field evidence`로 실패했으며, 검수 인용문이 해당 최종 문구에 포함되지 않는다는 검증에 걸렸다. 검수 게이트를 완화하거나 결과를 임의로 만들지 않았다. 이 검증에서는 제품 정책이나 모델 프롬프트를 변경하지 않았다.

APK는 기존 검증된 샘플 APK 그대로이며 PC 환경만 준비했다. 서버는 localhost:8765에서 실행 중이고 에뮬레이터 ADB reverse 연결을 유지했다. 실제 휴대폰이 아닌 emulator-5554 검증이다.
