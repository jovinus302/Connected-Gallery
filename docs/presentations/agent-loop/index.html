INNER LOOP

도구의 응답이 다시 agent에게.

Explorer는 행동을 선택하고 도구를 실행합니다. 도구의 출력은 다음 모델 입력으로 돌아옵니다. 검색 결과를 받으면 사진을 직접 확인하고, 확인한 결과를 바탕으로 후보를 제출합니다.

REVIEW FEEDBACK

검토의 피드백은 조건부로.

이 시연에서는 첫 후보가 모두 검토를 통과하지 못합니다. 선택 대상은 유효하고 결과는 불완전하며 실행 예산이 남아 있어, 검토 피드백으로 한 번 재탐색합니다. 항상 돌아가는 무한 loop는 아닙니다.

EXIT CONDITION

확인된 사진으로 결과를 구성.

결과 정리기가 연결된 구성을 시연합니다. 확인된 후보의 관계를 묶고 종료합니다. 실제 실행에서는 빈 결과나 불완전한 결과로 끝날 수도 있습니다. 이 화면의 사진·판정·시간은 설명을 위한 예시입니다.
