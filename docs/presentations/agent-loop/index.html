INNER LOOP

관찰이 다음 행동을 바꾼다.

검색 → 후보 정보 반환 → 사진 확인 → 이미지 반환의 왕복을 두 차례 보여줍니다. 요청과 응답에 내용을 붙이고, 받은 관찰이 다음 행동 선택에도 남습니다. 카메라는 실제로 접근·이동한 뒤 읽을 수 있는 구도에 정착합니다.

CONDITIONAL FEEDBACK

근거를 가지고 한 번 더.

첫 검토의 후보가 모두 미통과이고 결과가 불완전합니다. 원본 대상은 유효하고 응답·도구 예산이 남아 있어 한 번 재탐색합니다. 검토 피드백이 와인병의 구체적인 단서를 다음 검색에 반영합니다. 사진 위 표시는 시연용 주석입니다.

EXIT CONDITION

확인한 사진으로 마무리.

결과 정리기가 연결된 구성의 예시입니다. 독립 검토를 통과한 두 후보를 정리합니다. 실제 실행은 부분 결과·빈 결과·실패로 끝날 수도 있습니다. 사진과 판정은 고정 시나리오이며 내부 사고나 실제 모델 실행 기록이 아닙니다.
