# Astra / Blender 영상 제작 명제

2026-09-10 · 구현 전 기록 · **EXPERIMENT**

## 확정된 의도

사용자는 54초·35숏 기획안을 받은 뒤 “진행해”로 제작을 요청했다. 이번 실행은 그 본편을 Blender/Eevee로 제작하여, 재생할 수 있는 1080p/24fps 영상과 수정 가능한 원본을 전달한다. 무내레이션, 기존 사진 6장, 따뜻한 아틀리에, 파란 Explorer·호박색 Reviewer·검은 Organizer, 마지막 2.5초 `Made with Astra · Blender / Eevee`를 기획안의 기본값으로 실행한다. 별도 확장 영상과 새 사진 생성은 포함하지 않는다.

## 구현 해석

하나의 실제 3D 세트와 컷별 카메라·사진·Agent 안무를 재현 스크립트로 만든다. 후보 표식은 불투명한 물체, 실제 이미지 응답은 앞면 개방, 독립 검토는 원본/후보 비교, 정리는 검토된 사진의 배치로 표현한다. 사용자 선택은 별도 포인터로 보인다. 사진의 역할·근거 변화와 무음 가독성을 우선하며 소리·재질·조명은 이를 보조한다. 음악과 효과음은 이번 제작에서 직접 합성하고 출처와 생성 방식을 남긴다.

기획의 시간선과 제품 의미를 보존하는 구도·광량·재질·글자 크기 조정은 제작상의 선택이다. 러닝타임 또는 관찰/검토 과정의 삭제, 원본 선택·후보 범위·관계의 변경은 임의로 하지 않는다.

## 관찰 결과와 불변 조건

- 선택한 와인 검색 → 목록 → 이미지 관찰 → 독립 검토 → 전부 미지원인 첫 제출의 한 번의 조건부 재탐색 → 결과 1·2가 보인다.
- 피드백에는 원본의 실제 라벨 단서와 첫 후보가 남으며, 원본 선택이 유지된다.
- 사용자 식당 열기 → 사진 전체 기준 → 별도 후보 3·4 확보·전체 관찰·관계 및 문구 검토 → 설정 날짜 맥락이 보인다.
- 사용자 사람 선택 → 별도 Connect 결과 3·5 → 사용자 바닷가 열기 → 5 전체 기준의 별도 맥락 1·3을 보여준다.
- 정리기는 확보·검토된 범위 밖의 사진을 추가하지 않는다. 출발점은 새 결과로 중복하지 않는다. 삭제·소각 효과와 장식용 완전 그래프를 사용하지 않는다.
- 사진과 판정·날짜는 고정 예시임을 읽을 수 있게 표시하고, 실제 모델 실행·성능·내부 사고 또는 동일 물리적 병·구매·가족 관계를 주장하지 않는다.
- 기존 presentation/Agent loop/서버/Android/사용자 변경과 다른 worktree를 보존한다.

## 검증 계획

1. **구도·재질:** 대표 프레임을 낮은 해상도와 1080p에서 열어 실제 사진·라벨·인물, 유리 가림, 접촉·그림자, 한글 문구를 확인한다.
2. **동작·인과:** 낮은 해상도 연속 영상과 최종 영상의 장면을 관찰하고 후보/이미지/판정 등장 순서, 새 사용자 선택, 별도 전체 사진 작업, 피드백 보존을 확인한다. 스크립트의 의미 메타데이터와 실제 렌더 화면을 대조한다.
3. **매체:** 54초, 1296프레임, 1920×1080, 24fps, 오디오 길이·레벨, 전체 이미지 시퀀스와 MP4, 마지막 크레딧 60프레임을 검사한다.
4. **재현·납품:** `.blend`의 텍스처·폰트 포함 여부, 타임라인 편집 가능성, 스크립트/출처/실행 방법을 확인한다. 필요한 파일만 커밋·푸시하고 실제 미디어 경로를 전달한다.
5. **주장 구분:** 기술 검사·실제 이미지 판독·행동 해석·시네마틱 감상을 별도로 기록한다. 관객 조사나 실사용 모델 정확도를 수행했다고 주장하지 않는다.

## 가설 리뷰

**SOUND.** 기존 자료와 승인 기획의 흐름을 그대로 제작하며, 새 실행 정책이나 유료 의존성이 없다. 전용 worktree와 브랜치 `codex/astra-cinematic-film`에서 원본 자료를 보존한다. 재현 스크립트와 편집 가능한 장면으로 구도·타이밍을 수정할 수 있다. 현재 기획의 후반 압축과 사진 해상도는 대표 프레임·연속 편집으로 확인할 대상이다.

## 실행 증거

제작 중 얻은 검증 결과를 `validation.md`에 대응 항목별로 기록한다. 이 명제 작성 시점에는 완성 영상의 검증 결과가 없다.
