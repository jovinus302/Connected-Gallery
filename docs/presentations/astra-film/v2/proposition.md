# 동작과 읽는 시간을 다시 설계하는 2차 제작

2026-09-10 · 구현 전 기록 · **EXPERIMENT**

## 확정 의도와 새 증거

사용자가 1차 영상에서 “장면 전환이 뚝뚝 끊기고”, “에이전트는 움직이지도 않는데”, “설명란도 읽기 힘들게 지나간다”고 피드백했다. 사용자는 움직이는 Agent의 행동을 따라가며 사진이 연결되는 이유를 읽을 수 있어야 한다. 기존 proposition.md와 validation.md는 1차 제작 당시의 기록으로 보존한다. 그 기술 검사 PASS가 동작의 자연스러움이나 관객의 이해를 입증하지는 않았다. 이번 사용자 관찰은 그 부분의 실패 증거다.

## 원인과 선택한 해석

1차 구현은 35개의 독립 컬렉션을 순간 교체했고, 대부분의 Agent 동작은 시작 후 0.5~0.75초에 끝났다. 1~2초 장면마다 제목과 하단 설명이 함께 바뀌었다. 정확한 정지 프레임 재사용은 렌더 최적화일 뿐 원인이 아니다. 실제 안무와 편집 시간표를 바꿔야 한다.

**EXPERIMENT:** 같은 카메라와 지속하는 Agent 세 명을 중심으로, 사진을 잡기 → 함께 운반 → 내려놓기 → 손 떼기로 이어지는 동작을 만든다. Reviewer는 원본과 후보 사이를 오가며 두 방향을 차례로 살핀다. Organizer는 사진에 닿아 배열을 바꾼다. 표정 없는 재질 캐릭터이므로 몸의 기울기·팔·위치로 의도를 보여준다. 단순한 상시 회전이나 부유로 활동량만 높이지 않는다.

54초의 35숏 대신 약 85초의 연속 작업 장면과 마지막 크레딧으로 재편집한다. 사용자의 가독성·전환 수정 요청에 따른 시간 확장이다. 핵심 문장은 한 번에 한 개만 두고 4초 이상 유지한다. 후보 수신 같은 하위 동작이 일어나도 문구와 카메라는 계속 유지한다. 단순한 전체 감속, 모든 컷의 디졸브, 처리 단계 삭제는 선택하지 않았다. 사진/Agent 재질·빛·사용 사진은 재사용한다.

**제작 중 시간 조정:** 최종 관계 다섯 개를 읽기 전에 사진 여섯 장이 정리되는 동작에도 시간이 필요했다. 기존 85초 초안에서 최종 정리·경로 읽기를 5초 늘려 **90초**로 조정했다. 핵심 흐름과 가독성 조건은 유지하고 읽기 구간을 늘리는 변경이다. 마지막 4초는 크레딧을 고정한다.

**최종 안무 조정:** 동시에 사진을 운반하는 Organizer의 접촉·다음 동작을 검사하면서 마지막 정리에 3초를 더 배정했다. 최종 길이는 **93초**다. 마지막 경로는 84.3~89초에 유지하고, 89~93초는 크레딧을 고정한다. 이 변경은 동작과 읽기 시간을 늘리며 제품 흐름과 최소 문구 유지 시간을 줄이지 않는다.

## 불변 조건

- 첫 와인 후보 4·3 관찰과 독립 미지원 검토, 원본/실제 라벨/미지원 후보를 남기는 한 번의 조건부 재탐색, 새 후보 1·2 관찰과 독립 라벨 비교를 유지한다.
- 식당 전체 기준의 별도 후보 3·4 획득·관찰·날짜/문구 검토, 새 사용자 사람 선택의 Connect 3·5, 바닷가 전체 기준의 별도 후보 1·3 획득·관찰·검토를 유지한다.
- 후보 목록은 관찰 전 불투명하게 보인다. Organizer가 미확보 사진을 추가하거나 원본을 새 결과로 중복하지 않는다. 와인 미지원 사진을 지우지 않고 새 맥락에서 재사용한다.
- 최종 관계는 0–1, 0–2, 1–4, 1–5, 5–3 다섯 개만 사용한다. 설정 날짜와 생성 사진·고정 시나리오 고지, 정확한 Astra 제작 크레딧을 유지한다. 제품 실행·성능·관계 정확도의 실증으로 제시하지 않는다.
- 기존 영상과 원본은 보존하고 v2 경로에 새 산출물을 쓴다. 별도 유료 서비스·새 사진 생성은 없다.

## 관찰과 검증 계획

1. **연속성:** 카메라와 세 Agent가 동일 객체로 유지되는지, 장면 경계에서 위치가 튀지 않는지 측정하고 대표 운반/비교/정리 구간을 연속 영상으로 확인한다.
2. **행동:** 운반 중 손끝과 사진 접촉점의 거리, Reviewer의 원본→후보 이동, Organizer의 접촉 및 사진 동반 이동을 실제 평가된 3D 변환과 렌더로 확인한다. 동작량 자체를 자연스러움의 증거로 대체하지 않는다.
3. **읽기:** 핵심 문장 4초 이상, 중복 설명 없음, 사진의 판독 정지 구간과 글자 대비·화면 내 배치를 확인한다. 이 기준이 모든 관객의 읽기 완료를 보장한다고 주장하지 않는다.
4. **의미 보존:** 각 흐름의 목록→이미지→검토→정리 순서, 원본 유지와 새 기준 선택, 실제 사진 ID, 최종 관계 다섯 개를 검사한다.
5. **납품:** 연속 프리뷰를 먼저 검토한 뒤 1080p/24fps MP4, 편집 가능한 Blender 파일, 맞춘 음악·효과음, 검증 기록을 생성한다. 커밋·푸시한다.

## 가설 리뷰

**SOUND.** 사용자의 관찰과 구현의 짧은 동작·빈번한 장면 교체가 일치한다. 기존 제품 의미와 미술을 유지하며 안무·타이밍만 별도 버전에서 되돌릴 수 있게 바꾼다. 자연스러움은 수치 검사만으로 확정할 수 없으므로 실제 연속 영상 검토와 사용자의 후속 감상을 분리해 기록한다.

## 실행 증거
