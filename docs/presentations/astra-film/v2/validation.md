# 두 번째 편집의 제작 관찰 기록

**PASS · EXPERIMENT.** 2026-09-10, 최종 매체·편집 원본 검사와 브라우저 재생을 완료했다. 이 판정은 아래 관찰 범위의 제작 검증이며 사용자의 미적 승인이나 관객 이해도 실험 결과가 아니다.

## 1차 영상에 대한 사용자 증거

사용자는 “장면 전환이 뚝뚝 끊기고”, “에이전트는 움직이지도 않는데”, “설명란도 읽기 힘들게 지나간다”고 피드백했다. 1차 산출물의 기술 검사 PASS는 파일 형식·사진 범위·표기 등의 검사였다. 그 기록을 실제 관객의 가독성·자연스러움 승인으로 해석하지 않는다. 사용자 피드백 기준으로 1차의 해당 의도는 충족되지 않았다.

## 수정과 관찰

- **읽기:** 35개 독립 숏의 제목·설명 교체를 16개 핵심 문장으로 바꿨다. 앞의 15개 문장은 각각 4~7초, 마지막 정리 문장은 12초 유지한다. 초안 프레임에서 하단 설명과 Reviewer가 겹치는 것을 확인해 상단 고정 위치로 옮겼다. 확대된 식당 사진에서도 제목과 사진 테두리가 분리된다.
- **연속성:** 본편은 같은 카메라와 같은 세 Agent를 유지한다. 사진은 잡기·운반·놓기 동작으로 이동하고, 마지막 크레딧에서만 장면을 전환한다. 초안의 자동 이동 일정이 겹쳐 Explorer가 한 프레임에 2.333 단위 이동한 구간을 발견했다. 원본 위치와 역할별 동선을 바꾸고 바닷가 확대를 Organizer에게 맡겼다. 최종 안무에서 Explorer 최대 이동은 0.3604 단위/프레임이며, Reviewer와 세 Organizer 몸체를 포함한 최대값은 0.3869다. 이 수치는 갑작스러운 이동 검사이며 자연스러움 점수가 아니다.
- **접촉:** 평가된 3D 좌표에서 운반 중 손끝과 사진 모서리의 거리를 검사한다. 사진이 먼저 움직인 뒤 손이 뒤따르는 방식이 아니라 같은 운반 궤적을 사용한다. Reviewer는 원본과 후보 방향으로 차례로 이동한다. Organizer는 바닥을 이동하며 팔로 사진을 받친다.
- **연속 프리뷰의 발견:** 첫 16초 프리뷰를 브라우저에서 재생해 0초·4.84초·12.79초·끝 구간을 관찰했다. 설명은 유지됐지만 Organizer의 팔 곡선이 길게 꺾이는 현상이 보였다. 이동하는 제어점에 비해 곡선 손잡이가 이전 위치에 남는 문제를 수정하고, 실제 평가된 팔 표면이 현재 접촉 경로 주변에 머무는 검사를 추가했다. 이 프리뷰는 최종 승인 증거로 사용하지 않는다.
- **고해상도 관찰과 국소 수정:** 약 18초의 피드백 전달 프레임에서 Explorer와 Reviewer 몸이 겹치는 것을 확인했다. 받는 Explorer의 위치를 옮겼으며, 전체 2,232프레임의 가시 객체 변환과 팔 곡선을 수정 전후로 비교했다. 달라진 범위는 384~489번의 106프레임뿐이다. 몸체 분리와 사진 접촉 검사를 추가했다. 해당 프레임을 다시 출력해 교체하고 MP4와 편집 원본을 다시 만들었다. 최종 MP4의 18초 화면에서도 변경을 확인했다. 교체 전 결과와 비교 자료는 출력 폴더에 보존했다.
- **소리:** 요청/응답마다 반복되던 음형을 없애고, 2.4초 간격의 드문 음표와 운반 접촉 시점의 작은 효과음으로 바꿨다. 93초·48kHz·스테레오 음원의 피크는 −6 dBFS, RMS는 −20.52 dBFS이며 클리핑 샘플은 없다. 측정과 청취 감상을 구분한다.

## 제품 의미 보존

검사는 목록 → 불투명 후보 → 사진 확인 요청 → 실제 이미지 → 독립 검토 → 정리의 순서를 각 흐름별로 구분한다. 첫 와인 후보 4·3의 미지원, 같은 와인을 유지하는 한 번의 조건부 재탐색, 새 후보 1·2의 라벨 검토를 유지한다. 식당 전체 맥락 3·4, 별도 사람 선택 3·5, 바닷가 전체 맥락 1·3은 각각 새 획득·관찰·검토를 거친다. 최종 경로는 실제 사진 여섯 장과 지정된 다섯 관계만 포함한다.

## 최종 검증

| 검증 계획 | 실행 증거 | 판정과 한계 |
|---|---|---|
| 1. 같은 공간에서 이어지는 동작 | [scene-validation.json](scene-validation.json): 카메라 한 대, 동일한 세 역할, 다섯 몸체의 프레임 간 이동을 평가했다. 마지막 크레딧 전까지 카메라 교체가 없다. | PASS. 최대 이동 0.3869는 순간 위치 점프 검사이며 연기의 자연스러움 점수가 아니다. |
| 2. 사진에 닿아 운반하는 행동 | 같은 보고서의 운반 접촉 샘플 실패 0건, 평가된 팔 곡선의 잘못된 루프 없음, 피드백 전달 구간의 몸체 분리 검사 통과. [repair-validation.json](repair-validation.json)에 106프레임 교체와 나머지 장면의 동일 상태 비교를 기록했다. | PASS. 검사 대상은 저작된 접촉 구간과 명시한 몸체 분리 구간이다. 모든 가능한 충돌의 전역 증명은 아니다. |
| 3. 설명을 읽는 시간과 배치 | [timeline.json](timeline.json): 16개 문장, 앞 15개는 4~7초, 마지막은 12초. 최종 영상의 18초·34.5초·64초 화면과 후반부를 확인했다. 확대 사진 위에도 문구가 남고 화면 밖으로 잘리지 않는다. | PASS. 모든 관객의 읽기 완료나 선호는 측정하지 않았다. |
| 4. 제품 흐름과 사진 범위 | 장면 검사에서 5개의 별도 획득 흐름, 후보 10건의 독립 비교, 원본을 유지하는 한 번의 조건부 재탐색, 최종 사진 6장과 관계 5개를 확인했다. | PASS. 고정 시나리오의 표현이며 실제 모델 실행 또는 검색 정확도 실증은 아니다. |
| 5. 완성 영상과 편집 원본 | [media-validation.json](media-validation.json) 8개 검사, [delivery-validation.json](delivery-validation.json) 7개 검사, [preview-validation.json](preview-validation.json) 6개 검사 통과. 브라우저에서 최종 MP4가 끝까지 재생됐다. | PASS. 전체 PNG 디코딩, 영상 트랙 형식·시간, 오디오 형식, 편집 파일 경로·포함 자산을 구분해 검사했다. |

최종 영상은 **93초, 2,232프레임, 네이티브 1920×1080, 24fps, H.264/AAC**다. MP4는 37,382,445바이트다. 3D 원본은 40,209,796바이트, 최종 편집 원본은 40,274,240바이트다. 마지막 크레딧 96프레임은 동일하며, 그 이전에는 서로 다른 프레임 2,023개가 있다. 서로 다른 프레임 수를 가독성이나 좋은 연기의 지표로 사용하지 않는다.

Eevee 16샘플로 출력했다. [render-quality-check.json](render-quality-check.json)은 같은 네이티브 1080p 구도의 32샘플 대비 사진·문구·유리 영역 차이를 기록한다. 사진 내부의 평균 차이는 8비트 채널당 약 0.045다. 유리 표면에 남는 미세한 입자까지 없다는 주장은 아니다. 완전히 같은 가시 상태에서만 정지 프레임을 재사용했다.

최종 MP4를 브라우저에서 0~93.01초까지 연속 재생했다. 재생 중 22.62초, 45.57초, 55.48초, 78.42초와 크레딧을 표본으로 확인하고, 16초 피드백·33초 식당 열기·62초 바닷가 열기를 다시 탐색했다. 18초, 34.5초, 64초의 상세 프레임에서는 단서 전달과 확대 사진의 설명 배치를 확인했다. 마지막 관계 화면과 크레딧은 원본 1080p 프레임으로도 확인했다. 이는 재생 상태와 대표 화면의 관찰이며 모든 프레임을 사람이 연속 관찰한 평가나 관객 연구는 아니다. 브라우저 점검은 무음으로 수행했으며 음원의 청취 품질을 승인했다고 주장하지 않는다.

Blender 편집본의 2,232개 이미지 경로가 모두 해석됐고, 포함된 음원은 생성한 PCM 파일과 SHA-256이 일치했다. 원래 여섯 사진 시트의 바이트와 한글 글꼴 두 개의 포함 여부도 확인했다. 전체 시퀀스·음원·원본·문서·재제작 스크립트를 담는 패키지의 파일 수, CRC 검사와 SHA-256은 [package-validation.json](package-validation.json)에 별도로 기록한다.

## 구현 리뷰

| 관점 | 판단 |
|---|---|
| 의도 충족 | 짧은 독립 숏 대신 같은 공간의 행동을 이어 붙였다. Agent 몸·발·팔이 움직이고, 사진 운반과 접촉을 함께 저작했다. 설명은 한 문장씩 충분한 구간을 배정했다. 위 실행 증거가 해당 변화의 존재를 뒷받침한다. |
| 의도 누락 | 첫 후보 실패와 재탐색, 원본 유지, 새 전체 사진 기준, 별도 사람 선택, 이후 맥락의 독립 비교를 모두 유지했다. 가독성·자연스러움에 대한 사용자의 후속 평가는 아직 없다. |
| 의도 초과 | 54초를 93초로 늘린 해석과 대안은 구현 전 proposition 및 후속 시간 조정에 기록했다. 재생 시간을 줄이기 위해 제품 흐름을 생략하지 않았다. 새 유료 서비스나 사진 생성은 없다. |
| 프로젝트 정합성 | 기존 여섯 사진·재질·크레딧·생성 사진/가상 날짜/고정 시나리오 고지를 재사용했다. 기존 54초 영상과 원본은 보존했고 앱·서버 구현은 변경하지 않았다. |

**최종 구현 판정: PASS · EXPERIMENT.** 가설은 되돌릴 수 있는 두 번째 편집으로 구현됐으며 정해 둔 기술·표현 조건을 통과했다. 이 판정이 사용자의 미적 만족, 일반 관객의 이해도, 실제 모델 성능을 확정하지는 않는다.
