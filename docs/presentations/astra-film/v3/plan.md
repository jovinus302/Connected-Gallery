# v3 — Agent 역할을 알려주는 3D 안내

사용자 의도: 실제 Agent 모양의 회전하는 3D 심볼로 지금 누가 무엇을 하는지 알 수 있게 한다. 짧은 소개 후 같은 심볼이 구석으로 이동한다.

## 구현 순서

1. 기존 v2 영상·3D 원본의 해시를 기록하고 읽기 전용 입력으로 사용한다.
2. 원본의 세 Agent 형상을 이용한 독립 3D 안내 장면을 만든다. 7초 소개에서 `탐색 / 관련 사진을 찾고 확인해요`, `검토 / 연결 근거를 확인해요`, `정리 / 확인된 사진을 묶어요`를 보여준다. 마지막 1.5초에 오른쪽 위로 이동한다.
3. 본편 위에 같은 안내 장면을 합성한다. 이름은 고정하고 담당 심볼만 느리게 회전·강조한다. 설명은 기존 행동 시간표와 연결하며 사용자 선택·결과 감상도 구분한다.
4. 소개, 이동 완료, 탐색, 검토, 피드백, 정리와 마지막 장면의 정지 이미지 및 연속 프리뷰를 확인하고 크기·가독성·전환을 조정한다.
5. v3 MP4와 편집 가능한 Blender 파일, 시간표·검증 기록을 별도 경로에 저장한다. 길이·프레임·오디오·표시 범위를 확인한다.

## 보존 및 전달

- v1/v2 산출물과 서버·Android 코드를 변경하지 않는다.
- v2의 93초 본편에 7초 소개를 더한 100초, 1920×1080, 24fps를 목표로 한다.
- 원본 영상의 음원·동작 시점은 본편과 함께 7초 이동한다.
- 수정된 안내 레이어는 실제 실행 기록이 아닌 설명용 시나리오다. 기존 공개 문구와 크레딧을 유지한다.
- 렌더 중간 파일은 `outputs/astra-film/v3/`, 전달 파일은 이 폴더에 둔다.
