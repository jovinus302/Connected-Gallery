## 실제 화면을 보고 수정한 내용

- 사진에 들어오는 확산광을 줄여 과하게 밝아지는 라벨·얼굴을 조정했다.
- 선택 테두리의 자동 곡선을 직선 사각형으로 바꾸었다.
- 맥락 중심 사진과 제목의 겹침을 줄이고, 얼굴 위에 있던 중복 표기를 제거했다.
- 글자 재질을 조명에 영향받지 않게 하고 보조 문구의 대비·굵기를 높였다. 이 가독성 판단은 최종 해상도에서 확인한다. 270p 미리보기는 동작 확인용이다.
- S18·S27에서 Explorer 위에 겹치던 중복 보조 문구를 제거했다. 핵심 제목과 하단 설명은 유지했다.
- 최종 S30에서 선 위의 라벨/사람 표기와 어두운 카페 사진 위의 설정 날짜 표기를 발견했다. 관계명을 빈 공간으로 옮기고 이 36프레임만 다시 출력했다. 관계 선의 수·대상·전체 시간은 유지했다.
- 자동 좌표 검사에서 높은 사진으로 표시된 S09의 거리 사진은 제목 오른쪽에 떨어져 있다. S25는 큰 바닷가 사진을 감상하는 무제목 숏이어서 제목과 충돌하지 않는다.

설치된 Blender 5.2의 동영상 저장은 `image_settings.media_type='VIDEO'`가 먼저 필요했다. 첫 변환 실패를 이 설정으로 수정하고 내장 인코더로 미리보기를 생성했다. 재생 시 구간 이동을 확인하기 위해 로컬 확인 서버에 HTTP byte range 응답을 추가했다. 이 확인 도구는 제품 코드 변경이 아니다.

## 음악과 검증 한계

직접 합성한 48kHz 스테레오 PCM은 2,592,000 샘플, 정확히 54초다. 피크 약 −3dBFS, RMS 약 −17.62dBFS이며 클리핑 샘플은 0개다. 미리보기 MP4의 영상 트랙은 54초이고 컨테이너/브라우저는 AAC 패딩으로 약 54.02초를 표시한다. 음량·트랙 검사는 청취 패널 평가가 아니다.

실제 모델 실행, 사람 식별 정확도, 검색 수렴률, 성능, 실패 복구의 서버 동작, 관객 이해도나 브랜드 선호를 새로 측정하지 않았다. 사진 내용·날짜·판정은 고정 예시다. 기존 Agent loop의 과거 PASS 기록을 이번 영화 검증으로 재사용하지 않았다.

## 구현 리뷰

**PASS · EXPERIMENT.** 의도 충족: 승인된 54초 이야기, 실제 3D 원본, 음원, 1296프레임과 재생 가능한 최종 영상이 있다. 의도 누락: 본편에 계획된 관찰·독립 검토·새 기준 설정·크레딧을 생략하지 않았다. 의도 초과: 새 사진, 외부 모델 실행, 유료 서비스, 임의의 관계·날짜 주장을 추가하지 않았다. 프로젝트 정합성: 새 제작 폴더와 스크립트만 추가하며 기존 발표·Agent loop·서버·Android 구현과 다른 작업의 변경은 보존한다.

이 PASS는 관찰 가능한 제작 결과와 보존 조건에 관한 것이다. 빠른 편집의 이해도와 미술 방향의 선호는 관객 검증이 남아 있는 가설이다. 검증 자료는 `scene-validation.json`, `media-validation.json`, `audio-validation.json`, `preview-validation.json`과 전체 프레임 폴더의 `render-evidence.json`에 있다. 최초 렌더는 약 36분 57초, S30의 가독성 수정 렌더는 약 66초가 걸렸다. 이는 이 PC에서의 제작 시간이며 제품 성능이 아니다.
