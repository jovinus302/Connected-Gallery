# 샘플 사진 포함 APK 변경 명제 — 2026-09-08

## 구현 전
- 확정된 의도: 일상 캡처·문서·실물 사진과 여행 준비·현장 사진 24장을 포함한 APK를 빌드해 에뮬레이터에 설치한다.
- AI 해석: 디버그 APK에 샘플 이미지 bytes만 포함하고 ‘샘플 사진 추가’로 MediaStore에 복사한다. 앱의 기존 사진 보기·서버 분석 흐름을 재사용한다. 사용자가 재실행·재설치해도 샘플 추가로 중복을 만들지 않는다.
- 관찰 가능한 결과: APK 내부 24장, 에뮬레이터 MediaStore와 갤러리의 샘플 24장, 캡처·문서·사진 상세 표시, 뒤로 가기, 반복 추가 시 24장 유지.
- 불변 조건: 기존 개인 사진과 앱 데이터 유지. 생성 프롬프트·평가 정답은 APK/서버의 분석 입력에 포함하지 않는다. 모든 예약·영수증·문서 정보는 가상 데이터. release APK에 샘플을 포함하지 않는다. 샘플 추가는 Android 10+ 개발용 기능이다.
- 검증 계획: 각 이미지의 육안·글자 확인, 파일 수·APK 내용 검사, Android 빌드/단위 테스트/lint, base64+SHA-256 설치, 실제 에뮬레이터에서 추가·중복 방지·사진 상세·복원 확인. 서버의 실제 모델 분석 여부는 별도 증거로 구분한다.
- 미결정 사항: 샘플의 실제 검색·맥락 품질은 24장 설치 성공만으로 확정하지 않는다. 별도 모델 실행과 결과 검수가 필요하다.

## 가설 리뷰
SOUND. 기존 갤러리 흐름에 사진 데이터만 공급하며 의미 판단을 하드코딩하지 않는다. 별도 버튼과 디버그 전용 데이터로 가역적으로 제공한다.

## 실행 증거

- 이미지: 24장 모두 PNG 디코딩 성공. 캡처는 전체 검수 시트, 생성 사진·문서는 각 원본을 확인했다. 핵심 상호·모델·일정·금액이 읽히며 혼동 후보는 지점/모델/연도가 다르다.
- APK: 24개 sample-gallery 자산의 SHA-256이 소스와 일치. release 자산은 0개. 46,037,497 bytes, SHA-256 `ecad831d48fb26a9723b16e89d4275a1140d8aae85e6ba2e44ba9a9922fe5ca4`.
- 빌드 게이트: Android 29 tests, failures/errors 0. lint 통과. 신규 API 호출의 명시적 SDK 분기 수정 후 확인했다. 공유 Gradle 캐시의 임시 파일 이동 오류는 단일 작업자·별도 실행 재시도로 해결했다.
- 기기 동작: emulator-5554에 해시 일치 후 설치. 샘플 추가 24장, 반복 클릭 ‘샘플 24장이 이미 있어요’, APK 덮어 설치 후에도 동일. 샘플 05의 기존 행을 IS_PENDING=1로 설정한 뒤 재시도해 같은 행이 IS_PENDING=0으로 복구되고 기존 23장 유지. 기기 파일 24장의 해시가 모두 소스와 일치했다.
- UI: 항공 예약 캡처, 탑승권 문서, 등대 사진을 상세 화면에서 확인하고 목록 복귀. crash 버퍼 항목 없음. 로컬 사진 표시를 확인했으며 검색·맥락 성공 증거로 대체하지 않는다.
- 별도 분석 환경: 사진은 PC에 24장 동기화됐지만 모델 라이브러리 미설치로 분석 제출/OCR 도구가 ModuleNotFoundError를 냈다. 분석 완료 0건. 이 작업에서 띄운 검증 서버만 중지했다. 분석 의존성·모델 준비와 실제 Connect/맥락 검수는 별도 미완료 범위다.
