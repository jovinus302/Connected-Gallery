# 디버그 APK 샘플 사진

Android 10 이상에서 디버그 APK의 **샘플 사진 추가**를 누르면 캡처·문서·일상·여행 이미지 24장을 기기 갤러리에서 볼 수 있다. 최초 사용 시 사진 접근을 허용한다. 서버가 없어도 추가한 사진을 목록과 상세 화면에서 볼 수 있다. 대상 탐색과 자동 맥락에는 별도로 PC 서버의 분석 환경이 필요하다.

샘플은 `Pictures/ConnectedGallerySamples/`에 저장된다. 같은 버튼을 다시 누르거나 APK를 `pm install -r`로 갱신해도 기존 샘플을 중복 추가하지 않는다. 중간에 끊긴 본인 소유의 미완료 항목은 재시도한다. 같은 이름으로 다른 내용이 저장돼 있으면 기존 사진을 덮어쓰지 않고 오류로 알린다. 앱 삭제 후 재설치로 미디어 소유권이 바뀌는 경우는 이 검증 범위에 포함하지 않는다.

## 데이터 구성

| 파일 번호 | 내용 |
|---|---|
| 01–04 | 식당·지도·제품·행사 저장 캡처 |
| 05–08 | 영수증·메뉴판·제품 설명서·행사 전단 사진 |
| 09–12 | 음식·헤드폰·야간 행사·공원 사진 |
| 13–16 | 다른 지점·다른 모델·지난해 행사·무관한 메모 캡처 |
| 17–20 | 항공·숙소 예약, 저장한 장소, 여행 일정 캡처 |
| 21–24 | 탑승권·입장권·등대·현지 음식 사진 |

업체·제품·예약·행사 정보는 가상 데이터다. 사진 속의 날짜는 문서의 가상 일정이고 파일의 실제 촬영일이 아니다. 동일 모델명이나 비슷한 풍경을 같은 물리적 개체·같은 장소로 확정하는 정답은 제공하지 않는다.

## 자산과 재현

자산은 `android/app/src/debug/assets/sample-gallery/`에 있으며 release 자산에는 포함하지 않는다. APK에는 번호가 붙은 PNG만 포함한다. 프롬프트·시나리오·기대 관계는 분석 입력에 넣지 않는다.

- 캡처 12장: `scripts/create-sample-captures.py`로 UI와 글자를 직접 렌더링했다. Pillow와 Windows Malgun Gothic 글꼴이 필요하다.
- 문서·일상·여행 사진 12장: 내장 ImageGen으로 생성했다. 최종 프롬프트는 [sample-photo-prompts.json](sample-photo-prompts.json)에 기록했다. 생성 결과 자체를 저장소에 보존하므로 빌드에 이미지 재생성이 필요 없다.
- 빌드: `android/gradlew.bat -p android assembleDebug testDebugUnitTest lintDebug`.
- 설치: `python scripts/install-device.py --serial emulator-5554`. 로컬과 기기의 SHA-256 대조 후 기존 앱 데이터를 유지하는 설치를 한다.

## 2026-09-08 검증

Android 테스트 29개(실패·오류 0), lint와 디버그 APK 빌드 통과. 소스 PNG 24장과 APK 내부 24장의 해시 일치, release 병합 자산의 샘플 0장 확인. APK 46,037,497 bytes, SHA-256 `ecad831d48fb26a9723b16e89d4275a1140d8aae85e6ba2e44ba9a9922fe5ca4`.

emulator-5554에 base64 설치 후 앱 버튼으로 24장 추가. 반복 추가와 APK 덮어 설치 후에도 24장 유지. 본인 소유 샘플 05의 MediaStore 항목을 미완료 상태로 설정한 뒤, 같은 행을 정상 상태로 복구하고 기존 23장을 유지하는 동작 확인. 복구 후에도 기기 파일 24장 모두 소스와 해시가 일치했다. 항공 캡처·탑승권 문서·등대 사진의 상세 표시와 목록 복귀, crash 버퍼 항목 없음 확인.

PC 서버 동기화로 사진 24장은 전달됐다. 사진 분석은 필요한 모델 라이브러리가 없는 환경에서 `ModuleNotFoundError`로 실패했으며 분석 완료 0건이었다. 반복 실패를 막기 위해 이 작업에서 시작한 검증 서버만 중지했다. 이 검증은 샘플 포함·설치·사진 보기에 대한 것이며 Connect와 자동 맥락의 품질 검증은 미완료다.
